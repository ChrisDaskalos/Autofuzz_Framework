The fake HAL header `autofuzz/fakes/stm32f1_hal/stm32f1xx_hal.h` was written
for AutoFuzz. It declares names and types from the ST HAL API (no ST code) so
that the firmware compiles on a PC; it is under the MIT license.

Tools that AutoFuzz uses at run time are not part of this repository and are
installed separately: clang/LLVM with libFuzzer and the sanitizers (Apache-2.0
with LLVM exception), CMocka (Apache-2.0), the Python packages `libclang`
(Apache-2.0 with LLVM exception) and `PyYAML` (MIT).
